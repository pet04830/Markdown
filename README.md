 Technical writing in Markdown
===============================

Markdown is just a simplified markup system written in plain text.
when we do more advances technical writing in markdown, 
it helps to remember that markdown basically follows 
standard that people had pretty agreed to when writing in 
plain text.

Lets take lists as an example. 
Think about how you'd write an *ordered list*, which is a list with numbers. 
How would you write that in plain text?

You ca also make sublists using extra spacing. Here is a bullet list with a sublist
inside the first item:

* First item
  * Sub-item
  * Another Sub-item
  * A third Item
* Second Item

you can also make sublist items in an ordered list, just make sure to use 
numbers (or stars/hyphens) in the sub items.
